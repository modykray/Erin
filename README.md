# Erin - WhatsApp Bot

A WhatsApp bot owned and run by Erin (modykray), built on the MeowSab framework.

Run: `npm install && node index.js`. Env: `BOT_NUMBER` (bot number, digits only), `SESSION_PATH` (where the login session is stored).

Credit: based on the open-source Pomni-AI by deveni0 (https://github.com/deveni0/Pomni-AI).
